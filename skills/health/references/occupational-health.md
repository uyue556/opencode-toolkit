## 风险评估

### 久坐风险评分 (Sedentary Risk Score)

每个维度0-10分:
1. 每天久坐时间:>8h=10 / 6-8h=7 / 4-6h=4 / <4h=1
2. 休息频率:无休息=10 / 每3h+=8 / 每2h=5 / 每小时=2
3. 每周运动时间:0min=10 / <60=7 / 60-150=4 / >150=1
4. 现有症状:严重=10 / 中度=7 / 轻度=4 / 无=1

总分4-40分:**低风险4-13 / 中风险14-26 / 高风险27-40**。

### 视屏终端风险评分 (VDT Risk Score)

1. 每天屏幕时间:>8h=10 / 6-8=7 / 4-6=4 / <4=1
2. 20-20-20法则:从不=10 / 偶尔=6 / 经常=3 / 总是=1
3. 照明条件:很差=10 / 较差=7 / 一般=4 / 良好=1
4. 眼部症状:严重=10 / 中度=7 / 轻度=4 / 无=1

### 综合风险等级

```
综合分数 = max(久坐, 视屏, 倒班, 劳损, 压力)
若≥2个高风险(≥27分)或≥3个中风险(14-26分)→ 综合等级上调一级
```

## 人机工程评估

总分0-100分(每项0-20分):
- 椅子:可调节性/腰椎支撑/座椅深度/扶手(各0-5)
- 显示器:高度/距离/角度(7/7/6)
- 键盘鼠标:键盘位置/鼠标位置/手腕支撑(5/5/10)
- 工作台:高度/空间(10/10)
- 环境:照明/噪音/温度(7/7/6)

**等级**:优秀0-20 / 良好21-40 / 一般41-60 / 较差61-80 / 差81-100。输出改进建议(逐项)。

## 职业病筛查

基于工作类型的筛查推荐(如久坐办公→颈椎/腰椎/代谢综合征筛查;视屏操作→干眼/视疲劳/腕管综合征筛查;倒班→睡眠障碍/代谢/心血管筛查)。输出:推荐筛查项目与频率。

## 关联分析

- **睡眠-职业**:倒班与睡眠质量
- **运动-职业**:活动量与久坐风险
- **心理健康-职业**:工作压力与心理状态

## 报告

职业健康分析报告结构:摘要 → 风险评估结果(久坐/VDT) → 工作相关问题分析(活跃问题/症状趋势) → 人机工程评估与改进建议 → 职业病筛查推荐 → 综合建议(立即行动/本周计划/预防措施)。

**免责声明**:不诊断职业病,筛查建议仅供参考;疑似职业病请至职业病专科就诊。
