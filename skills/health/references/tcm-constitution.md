## 体质辨识算法

60题标准化问卷,5分制(没有/很少/有时/经常/总是)。

```python
转化分数 = [(原始分数 - 题目数) / (题目数 × 4)] × 100   # 0-100分

# 判定逻辑
# 1. 平和质: 得分≥60 且 其他8种体质均<40
# 2. 偏颇体质: 最高分体质为主导
# 3. 兼夹体质: 次高分≥40 则为兼夹
```

## 九种体质要点

| 体质 | 特征 | 发病倾向 | 调养方向 |
|------|------|----------|----------|
| 平和质 | 健康平衡 | 少病 | 保持 |
| 气虚质 | 易疲乏、气短、自汗、声音低弱 | 易感冒、内脏下垂 | 补气健脾 |
| 阳虚质 | 畏寒怕冷、手足不温、喜热饮 | 痰饮、肿胀、腹泻 | 温补肾阳 |
| 阴虚质 | 手足心热、口干 | 虚火、失眠 | 滋阴清热 |
| 痰湿质 | 体胖腹满、身重 | 高血压、糖尿病、高血脂 | 健脾化湿、低脂低糖 |
| 湿热质 | 面垢油光、口苦 | 代谢综合征 | 清热利湿 |
| 血瘀质 | 面色晦暗、易瘀斑 | 心血管疾病 | 活血化瘀 |
| 气郁质 | 情志抑郁、多愁善感 | 抑郁、焦虑 | 疏肝解郁 |
| 特禀质 | 过敏体质 | 过敏性疾病 | 固表防过敏 |

## 养生建议

**饮食调养**:宜食/忌食清单、推荐食谱、原则(如气虚质:补气健脾温阳,宜山药/大枣/黄芪/羊肉/韭菜,忌生冷油腻辛辣;方剂参考四君子汤加减——仅供中医师参考,不可自行抓药)。

**起居调摄**:作息、环境(保暖防风寒)、生活习惯(温水泡脚、劳逸结合)。

**运动锻炼**:气虚/阳虚质→温和运动(太极/八段锦/散步/气功/瑜伽),每日1-2次每次20-30min低中强度;湿热/痰湿质可适度加强;阴虚质避免剧烈运动。

**情志调摄**:保持心情舒畅、避免过度思虑、社交活动。

**穴位保健**:足三里(膝眼下3寸,健脾益气)、气海(脐下1.5寸,培补元气)、关元(脐下3寸,温补肾阳),每日按揉3-5min可艾灸。

**中药调理**:⚠️ 仅供中医师参考,需辨证后使用;孕妇/儿童/体弱者需医师指导;服药期间忌生冷油腻辛辣;感冒发烧停服;不良反应立即停药就医。

## 季节调养

- **春**:养阳顺应生发,食韭菜/菠菜/山药,防风保暖。
- **夏**:清暑养心,食绿豆/冬瓜/苦瓜,防暑降温。
- **秋**:养收润燥养肺,食银耳/百合/梨,避凉。
- **冬**:养藏温补肾阳,食羊肉/核桃/栗子,保暖,早睡晚起。

## 体质与健康指标关联

- 营养:气虚阳虚宜温补,阴虚湿热宜清淡,痰湿宜低脂低糖控体重。
- 运动:气虚阳虚温和,湿热痰湿加强,阴虚避剧烈。
- 睡眠:气虚阳虚保充足睡眠,阴虚避熬夜,气郁疏肝解郁。
- 慢性病:痰湿→高血压/糖尿病/高血脂,湿热→代谢综合征,血瘀→心血管,气郁→抑郁焦虑。

## 安全边界

- ✅ 体质辨识评估、特征分析、一般养生建议、中医知识普及、趋势追踪。
- ❌ 中医疾病诊断、中药处方开具、替代中医师诊疗、针灸等治疗操作。
- 危险信号:单一偏颇>80分、多种偏颇兼夹、疑似疾病症状→建议就医;调理无效→寻求专业帮助。
- 建议分级:L1一般性(无需监督)/L2参考性(建议咨询中医师)/L3医疗级(中药调理需中医师确认)。
