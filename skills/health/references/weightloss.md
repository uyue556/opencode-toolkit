## 身体成分分析

**BMI** = 体重(kg)/身高(m)²。WHO亚洲标准:偏瘦<18.5、正常18.5-24、超重24-28、肥胖≥28。

**体脂率**:男 15-20%正常/20-25%偏高/>25%肥胖;女 20-25%/25-30%/>30%。

**围度**:
- 腰围:男<90cm正常,≥90cm腹部肥胖;女<85cm正常,≥85cm腹部肥胖。
- 腰臀比:男<0.9、女<0.85为正常,超过则为腹部肥胖。

**理想体重**:BMI法 = 身高²×22;Broca修正 = (身高cm-100)×0.9。

## 代谢率计算

**BMR公式**:
- Mifflin-St Jeor(推荐,最准确):男 = 10×kg + 6.25×cm - 5×age + 5;女 = 10×kg + 6.25×cm - 5×age - 161
- Harris-Benedict(1919):男 = 88.362 + 13.397×kg + 4.799×cm - 5.677×age;女 = 447.593 + 9.247×kg + 3.098×cm - 4.330×age
- Katch-McArdle(基于瘦体重):BMR = 370 + 21.6×瘦体重kg;瘦体重 = 体重×(1-体脂率)

**TDEE** = BMR × 活动系数:久坐1.2/轻度1.375/中度1.55/高度1.725/非常高度1.9。

报告建议同时给出三个公式的BMR表并推荐Mifflin值。

## 能量缺口管理

- 每日缺口 = TDEE - 实际摄入 + 运动消耗。
- 1kg脂肪 ≈ 7700大卡;预计周减重 = 每日缺口×7/7700。
- 安全减重速度 0.5-1kg/周(缺口500-1000大卡/天)。

**三档方案**:温和缺口500(约0.5kg/周)、积极缺口750(约0.75kg/周)、快速缺口1000(1kg/周,仅短期,⚠️需检查热量不低于安全下限)。

**热量安全边界**:男≥1500大卡/天、女≥1200大卡/天、绝对下限=BMR×1.2。

## 阶段管理

**减重期**:追踪体重变化、进度百分比((已减/总目标)×100)、减重速度(kg/周,健康范围0.5-1,最大不超1.5)。

**平台期检测**:定义=2周以上体重波动<0.5kg。原因=代谢适应/水分滞留/肌肉增加。突破=调整热量、改变运动、间歇性断食。

**维持期**:目标体重±2kg内,定期监测,及时调整。

## 报告与命令

输出报告:身体成分分析报告 / 代谢率分析报告 / 能量缺口追踪报告(周汇总表:摄入|运动消耗|NEAT|缺口|达标)/ 阶段管理报告。

命令示例:
```
/fitness:weightloss-setup --weight 75 --height 175 --age 52 --gender male
/fitness:weightloss-bmr --formula mifflin
/nutrition:weightloss-track --intake 1800 --exercise 350
/fitness:weightloss-report
/fitness:weightloss-plateau-check
```

## 安全边界

- 不推荐<1200(女)/<1500(男)大卡/天,绝对最低不低于BMR×1.2。
- 减重速度安全范围0.5-1kg/周,长期平均0.5-0.8kg/周。
- 就医场景:BMI>35、心脏病/高血压/糖尿病等慢性病、服用处方药、孕期哺乳期、健康状况不确定。
