## 医学安全边界

**不能做**:心理疾病诊断、开精神药物处方、预测自杀风险或自伤行为、替代专业心理治疗、处理急性精神危机。
**能做**:识别趋势与模式、评估危机风险等级并预警、提供非治疗性应对策略建议、追踪治疗进展、提供就医建议与资源、跨模块关联分析。

## 核心功能

1. **评估趋势**:PHQ-9/GAD-7评分时序、变化速率(分/月)、严重程度变化、PHQ-9第9项(自伤意念)变化、PSQI与心理评分相关性。
2. **严重程度检测**:快速恶化(≥5分/月=危机预警)、快速改善(强化有效策略)。PHQ-9分界:5/10/15。
3. **治疗进展**:目标完成百分比、症状改善(基线→当前→目标)、作业完成率、治疗频率与依从性。
4. **情绪模式**:常见情绪Top5、时间模式(早/中/晚)、周模式(工作日/周末)、波动程度(方差)、触发因素Top10、应对方式效果评估(>80%有效=高效,<50%=低效)。

数据:`data-example/mental-health-tracker.json`、`mental-health-logs/`。趋势分析至少3次量表评估或7天情绪日记。

## 危机风险评估

**风险评分(总分0-20+,各维度加分)**:
1. PHQ-9第9项:得分2(经常)=+10且直接判定高风险;得分1(有时)=+5;得分0=+0
2. 症状变化:快速恶化(≥5分/月)=+5;恶化(2-4)=+3;稳定=+0;改善(≤-2)=-2
3. 高强度负面情绪占比:>70%=+3;50-70%=+2;<50%=+0
4. 情绪波动方差:>6=+2;4-6=+1;<4=+0
5. 危机预警信号:每个=+2
6. 社会退缩:严重(独处>80%)=+3;中度(50-80%)=+2;轻度=+0
7. 功能受损:严重(≥5天/周)=+4;中度(3-4天)=+2;轻度=+0

**等级判定**:高风险≥10分(立即就医、启动危机干预);中风险5-9分(48h内考虑就医);低风险0-4分(继续监测)。

**预警信号**:绝望感、社会退缩、极端情绪波动、谈论死亡、送走财物、自伤意念、自杀想法、物质滥用。

**紧急行动触发**:
- 立即(24h内):PHQ-9第9项≥2、总分≥10、幻觉或妄想、有自伤/自杀计划
- 尽快(48h内):PHQ-9或GAD-7≥15、总分5-9、快速恶化、严重影响功能
- 定期(1月内):PHQ-9/GAD-7 10-14分、症状持续

**紧急资源必须输出**:心理危机热线(24h)、就近精神科急诊、急救电话120、家人朋友陪伴。

## 情绪模式识别

- 常见情绪占比与平均强度(如焦虑35%/强度7/10)。
- 触发因素按频次与影响(高影响+高频=高危触发因素)。
- 应对方式排名表:有效次数/无效次数/有效率/排名。

## 跨模块关联

- **睡眠-心理**:时长与PHQ-9负相关(r≈-0.72);PSQI每改善1分,PHQ-9平均降1.2分;入睡困难→次日焦虑+40%。
- **运动-情绪**:运动日情绪强度+1.5分;有氧运动改善率85%>瑜伽80%>散步75%;每周3-5次30min+。
- **营养-心理**:咖啡因与GAD-7正相关(r≈0.52);高糖与情绪波动相关;Omega-3不足或与抑郁相关。
- **慢性病-心理**:慢性疼痛与抑郁、疾病负担与焦虑、药物副作用对情绪、共病模式。

输出:关联强度(高/中/低)、主要发现、针对性建议。

## 报告结构

心理健康分析报告包含:危机风险预警(置顶)→ 状况摘要 → 评估趋势(PHQ-9/GAD-7/PSQI) → 情绪模式 → 触发因素 → 应对方式效果 → 治疗进展 → 危机风险评估(因素得分表) → 跨模块关联 → 综合建议 → 数据质量说明。

示例输出参考:
```
/mental trend 3months   → PHQ-9: 14→8分改善6分,趋势改善✓
/crisis assessment       → 风险等级+评分/20+因素表+建议行动
/mental pattern          → 常见情绪+时间模式+触发因素+高效应对策略
/mental therapy progress → 治疗概况+目标进展表+症状改善%+作业完成率
```
