## 家族病史分析

数据源:`data/family-health-tracker.json` + 高血压/糖尿病tracker + profile。

**分析步骤**:确定目标(病史/遗传/趋势/报告) → 读取数据 → 验证清洗(关系完整性/年龄合理性/一致性) → 遗传模式识别(家族聚集性/遗传模式/早发病例<50岁) → 风险计算 → 预防建议 → 报告。

**识别算法**:家族聚集性分析、遗传模式识别、早发病例识别(通常<50岁)。

## 遗传风险计算

```python
遗传风险评分 = (一级亲属患病数 × 0.4) +
              (早发病例数 × 0.3) +
              (家族聚集度 × 0.3)

# 风险等级: 高风险≥70% / 中风险40-69% / 低风险<40%
```

**医学边界**:仅基于家族病史统计,不诊断遗传病、不预测个体发病概率、不推荐具体治疗方案。每次输出必须包含免责声明(统计参考/不预测个体发病/咨询医师/咨询遗传咨询师)。

## 预防建议与报告

建议分类:
- 筛查建议:`{category: screening, action: 定期血压监测, frequency: 每周3次, start_age: 35, priority: high}`
- 生活方式建议:饮食、运动、作息
- 就医建议:何时就医、咨询专科

**HTML报告组件**:家谱树(ECharts树图)、遗传风险热力图、疾病分布饼图、预防建议时间线。

## SMART目标验证

验证新目标的SMART维度:
- **S**pecific具体:定义清晰、避免模糊
- **M**easurable可衡量:量化指标、可追踪
- **A**chievable可实现:现实可行;参考:减重每周0.5-1kg、运动每周3-5次每次30-60min
- **R**elevant相关:与健康计划协调
- **T**ime-bound有时限:截止日期、阶段里程碑

**评分**:每维度1-5分,总体评分与等级(S/A/B/C),改进建议与优化方案。示例:`"6个月内减重5公斤"` → specific5/measurable5/achievable4/relevant5/time_bound5 → 4.8分A级。

## 目标进度与习惯

**进度追踪**:当前值vs目标值、完成百分比、预估达成时间、滞后目标识别。趋势分析+达标率。

**习惯养成分析**:习惯执行频率、一致性、触发-行为-奖励链分析、中断原因。

**习惯热图**:周中每日执行情况可视化。

## 动机与障碍管理

- **动机评估**:动机水平趋势、高低谷识别、激励因素/削弱因素。
- **障碍识别**:时间/精力/环境/心理障碍分类,针对性解决方案。
- **成就系统**:里程碑解锁、奖励机制、强化坚持。
- **数据关联**:目标进度与营养/运动/睡眠数据的关联(强相关因素影响度>60%标出)。

**报告**:目标概览 → SMART评估 → 进度分析 → 习惯追踪 → 动机评估 → 数据关联 → 障碍识别 → 成就解锁 → 下一步行动。可选HTML可视化(ECharts:进度趋势/习惯热图/多目标对比/动机趋势)。

**免责声明**:目标管理建议不构成医疗方案;存在心理障碍或健康风险时建议寻求专业帮助。
