## 通用工作流

1. **确定范围**:分析类型(趋势/评估/相关性/建议)与时间范围。默认3个月,支持"过去1个月/6个月/1年/最近90天/自定义日期段"。
2. **读取数据**:主数据文件 + 按月份日志目录。过滤函数:
   ```javascript
   function filterByDate(data, startDate, endDate) {
     return data.filter(item => {
       const d = new Date(item.date || item.created_at);
       return d >= startDate && d <= endDate;
     });
   }
   ```
3. **数据验证**:文件存在性、结构完整性、数据点充足性。趋势分析最少1个月,相关性分析需要更多数据点。
4. **趋势分析**:线性回归斜率、移动平均、方向与幅度。
5. **相关性分析**:Pearson / Spearman / 滞后相关 / 交叉相关。
6. **变化检测**:CUSUM、滑动窗口t检验、贝叶斯变化点。
7. **风险与模式识别**:按子领域专用评分表。
8. **报告生成**:文本 + HTML(ECharts)。

## 趋势分析算法

- **线性回归**:`斜率slope = Σ((x-x̄)(y-ȳ)) / Σ(x-x̄)²`,判断上升/下降/稳定。
- **移动平均**:平滑短期波动,典型窗口3天或7天。
- **季节性分析**:周期/星期效应(工作日 vs 周末)。
- **异常值检测**:`|x - mean| > 2×std` 标记。
- **变化率**:环比、同比。

统计指标输出:均值、中位数、标准差、百分位数(25/50/75)。

```javascript
// 应用场景
- 药物开始日期 vs 症状频率
- 睡眠时长 vs 情绪评分
- 体重变化 vs 饮食记录
- 运动量 vs 情绪状态
```

**解释规则**:
- |r| < 0.3:弱相关
- 0.3 ≤ |r| < 0.7:中等相关
- |r| ≥ 0.7:强相关
- p < 0.05 统计学显著
- 措辞用"识别出中等相关(r=0.62)",不推断因果。

## 变化检测算法

- **CUSUM**:累积和检测均值漂移。
- **滑动窗口t检验**:比较两时间窗均值差异。
- **贝叶斯变化点检测**:估计变化点概率。

**阈值警报**:检查指标接近或超过危险阈值(BMI>30、辐射剂量超限、快速体重下降>5%/月等)。

## HTML可视化报告

生成独立HTML文件(ECharts通过CDN),包含:
1. 总体评估卡片
2. 双Y轴折线图(如体重+BMI)
3. 颜色编码柱状图(高频红/中频黄/低频绿)
4. 仪表盘(依从率等)
5. 多系列折线图 + 参考线(化验指标)
6. 相关性热力图
7. 双Y轴面积图(情绪与睡眠)

要求:完全独立、交互式(缩放/导出/图例切换)、响应式、可打印、可分享给医生。

## 错误处理

- **无数据**:输出"暂无数据,建议先记录[数据类型]"。
- **数据不足**:输出"数据不足(趋势分析需要至少1个月数据)"。
- **范围窄**:用现有数据,提示延长记录时间。
- **无法计算趋势**:提示"数据点不足"。
- **相关性失败**:提示"相关性分析需要更多数据"。
- **图表渲染失败**:降级为文本报告。

## 性能与工具

- **工具限制**:仅 Read / Grep / Glob / Write,无需额外权限。
- **性能优化**:增量读取(仅指定时间范围)、数据缓存、延迟计算。
- **扩展性**:支持添加新数据维度、自定义图表类型与分析算法。
- 对>6个月大数据:按周/月聚合、随机抽样、增量分析、缓存中间结果。

## 安全与隐私(通用于所有子领域)

- ❌ 不给出医疗诊断、不用药建议、不判断生死预后。
- ✅ 仅基于已记录数据分析,不推测缺失信息;标注数据来源与时间范围。
- ✅ 所有数据保持本地,无外部API调用;HTML报告独立运行无数据传输。
