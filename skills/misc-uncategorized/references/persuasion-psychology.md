# Conversion Psychology / Persuasion

Consolidates the "psychologist" family (all date_added 2026-04-04, same template, distinct
perspectives): customer-psychographic-profiler, awareness-stage-mapper, jobs-to-be-done-analyst,
headline-psychologist, subject-line-psychologist, pitch-psychologist, loss-aversion-designer,
social-proof-architect, scarcity-urgency-psychologist, trust-calibrator, sequence-psychologist,
emotional-arc-designer, visual-emotion-engineer, ux-persuasion-engineer, objection-preemptor,
identity-mirror, price-psychology-strategist, brand-perception-psychologist, onboarding-psychologist.

## Shared Method

Every skill in this family follows the same pattern:
1. **Context gathering** — Target Human (psychographic profile, awareness stage, trust stage),
   Objective (the action/belief to produce), Output (copy, flow, audit, strategy), Constraints
   (channel, category norms, ethics). Ask before proceeding only if essential context is missing.
2. **Psychological framework** — one named mechanism with cited research basis.
3. **Execution steps** — 5 concrete steps.
4. **Decision matrix** — variable → response (awareness stage, trust level, channel, etc.).
5. **Failure modes** — what agents typically do wrong, why it fails, what to do instead.
6. **Ethical guardrails** — no fake scarcity, no false certainty, no dark patterns, no
   identity overclaiming; the line between persuasion and manipulation is a real gap vs a
   manufactured one. Never cross it.

Chain: customer-psychographic-profiler → awareness-stage-mapper → (JTBD) → headline/subject/
pitch/sequence skills → output quality check.

## 1. Customer Psychographic Profiler

Build a deep psychological profile: not demographics. Infer the dominant need state (security,
competence, autonomy, belonging, status, self-expression, self-actualization), identity
commitments (what they want to be seen as / refuse to be seen as), fears & frictions (separate
rational objections from emotional threat), values, aspirations, motivators, language cues,
buying triggers. Decision matrix: identity-central → emphasize self-concept/belonging; trust low →
proof/transparency; motive avoidance → relief/safety, achievement → competence/status, belonging →
community.

## 2. Awareness Stage Mapper

Classify the audience: unaware → problem aware → solution aware → product aware → most aware.
Each stage needs a different persuasion route (ELM): unaware/problem-aware = educational framing;
later stages = comparative proof. Calibrate language register to stage; recommend the right first
touchpoint (education, proof, demo, comparison, offer). Never pitch a solution to an audience that
hasn't named the problem.

## 3. Jobs-to-be-Done Analyst

Define the progress state (before → after in plain language). Separate three job layers:
functional, emotional, social. Find the hiring trigger (pain, frustration, opportunity, identity
threat). List competing alternatives including manual workarounds, status quo, adjacent
substitutes. Specify success criteria in the customer's terms. Failure modes: feature-list called
JTBD; collapsing emotional/social jobs into one vague statement.

## 4. Headline Psychologist

Curiosity-contrast engine: (1) pick the required mental state (urgency/curiosity/reassurance/
surprise/identity), (2) create an attainable information gap, (3) add self-relevance, (4) calibrate
tension to trust, (5) remove clickbait residue (content must resolve the promise).
Awareness-stage matrix: unaware → problem recognition; problem-aware → pain/cost/contradiction;
solution-aware → differentiation/mechanism; product-aware → proof/precise benefit; most-aware →
next action. Channel: email → clarity/trust; ads → short pattern-interrupt; landing → relevance;
social → conversational tension + shareability. Trust low → clarity over mystery.

## 5. Subject Line Psychologist

Subject lines earn opens. Mechanism: attention + curiosity + inbox trust. Variants: curiosity
gap, benefit clarity, urgency (calibrated), specificity, personal relevance. Match to awareness
stage and channel; preserve promise continuity (subject ↔ body). No fake urgency, no deceptive
openers.

## 6. Pitch Psychologist

Structure the pitch around a psychological arc: attention → relevance → tension → proof →
resolution → action. Match the pitch's emotional content to the audience's trust and readiness;
make the ask concrete and autonomy-preserving. Failure mode: cramming everything into one pitch;
leading with features instead of progress.

## 7. Loss Aversion Designer

Reference-point framing: people weigh losses ~2x gains. Execution: establish the reference point
(what they already have/current state), frame the offering relative to it, use loss framing
("what you're leaving on the table", "what this costs you not to act") only when honest and
relevant, pair loss framing with a gain to stay ethical. Audience risk tolerance: risk-averse →
loss-framing works; cynics → factual framing. Never manufacture false loss.

## 8. Social Proof Architect

Match the proof type to the audience's skepticism and the decision stage. Proof hierarchy:
authority (experts), peers (similar users), volume (numbers), specificity (detailed case),
recency, independence (third-party). For low-trust categories use more explicit, verifiable proof;
for high-trust keep it minimal. Failure modes: generic testimonials with no specificity; proof
that doesn't match the objection; overclaiming.

## 9. Scarcity / Urgency Psychologist

Genuine scarcity calibration: use only real, bounded scarcity (limited seats, expiring offer,
genuine deadlines). Never fabricate. Audience cynicism: high cynicism → factual deadline +
transparency; low → lighter touch. Ethical guardrail: false scarcity destroys trust permanently.

## 10. Trust Calibrator

Credibility ladder: identify the trust barrier (competence, benevolence, integrity, legitimacy),
diagnose category baseline (trusted/distrusted/polarized), select the trust signal (proof,
transparency, credentials, endorsements, process visibility), sequence it before the highest-risk
decision, check for overclaiming. Trust barriers → signals: competence → expertise/process/results;
benevolence → care/support; integrity → transparency/consistency; legitimacy → compliance/
certification.

## 11. Sequence Psychologist

Commitment-pacing sequence: define each email's emotional job; open a loop (curiosity gap the
next email answers — Zeigarnik); give value before asking (reciprocity); escalate commitment
gradually (foot-in-the-door); end with a clean, autonomy-preserving decision. Sequence length:
short = 3-5 email arc; medium = educate/proof/objections/ask; long = staged relationship arc.
Cold → lead with value; warm → proof + identity + urgency; hot → move to decision. Never make
every email close.

## 12. Emotional Arc Designer

Map entry emotion → engineered progression → destination emotion (the emotion needed to act).
Pick the smallest believable transition path (no hard jumps — abrupt shifts raise skepticism);
place the peak moment where the key insight/proof/offer lands (peak-end effects); engineer the
exit state for the next action. Entry anxiety → reduce uncertainty first; skepticism → proof first;
curiosity → escalating tension. High-commitment action → trust → desire → urgency; return-visit →
end with anticipation.

## 13. Visual Emotion Engineer

Map color, typography, spacing, imagery to a target emotion. Target emotion: calm (low contrast,
whitespace), trust (restrained color, transparent structure, realistic imagery), urgency (higher
contrast, tight focal points), prestige (minimalism, controlled spacing), warmth (soft hues,
human imagery). Cultural context: color-emotion is NOT universal — calibrate to market. Novice →
reduce noise; expert → support precise scanning; never over-decorate (clutter raises cognitive
load).

## 14. UX Persuasion Engineer

Choice architecture: define ONE target behavior; audit friction (every unnecessary decision/
field/screen); design the default path as the easiest path; insert commitment points (small
yes-steps before the big ask); check for ethical pressure (guide, don't trap). Task complex →
break into steps; simple → compress; high-stakes → reassurance + review. Friction cognitive →
simplify decisions; emotional → reassurance/proof; physical → layout/spacing. More persuasion does
not fix a confusing flow — remove friction first.

## 15. Objection Preemptor

Inoculation without reactance: list likely objections (practical, emotional, trust, cost, effort,
identity); rank by psychological intensity (identity-linked objections create most defensiveness);
choose the neutralization mode (proof, reframing, comparison, limitation, guided choice); embed
answers where doubts naturally appear; verify the wording doesn't sound patronizing/coercive.
Early stage → preempt only the biggest objection; mid → 2-3; late → final barrier. Never list
every objection in one long section (plants new doubts).

## 16. Identity Mirror

Identify current self-concept and aspirational identity; define the identity gap; mirror language/
imagery/proof so the aspirational self feels recognized but achievable. Small gap → mirror +
affirm; medium → mirror + stretch; large → bridge with proof. Never overclaim identity fit
(creates dissonance); pick the single strongest identity signal rather than mirroring everything.

## 17. Price Psychology Strategist

Price signal architecture: set the reference point (anchor), choose the price structure (monthly/
annual/per-use/bundle/tier), use decoys only if they clarify the preferred option (asymmetrically
dominated alternatives), reduce pain of paying honestly (payment timing/bundling), check quality-
signal collapse (discount framing can damage premium positioning). Price-sensitive → affordability;
premium-sensitive → quality signals. Fake anchors trigger suspicion — use credible anchors tied to
real alternatives.

## 18. Brand Perception Psychologist

Brand schema alignment: identify the current subconscious impression, compare to intended
position, find the largest mismatch across visual/verbal/behavioral layers, prescribe the smallest
useful correction (highest-salience signal first), verify cross-touchpoint consistency. Changing
the logo alone is not repositioning. One mismatched signal can weaken the whole impression
(halo/schema effects).

## 19. Onboarding Psychologist

Identity-to-habit onboarding: define the first win (smallest meaningful success), remove
unnecessary setup, create ownership through action (labor/endowment effect), attach a stable cue,
reinforce identity. Low readiness → almost effortless first win; daily-use product → cue stability;
intrinsic motivation → autonomy/mastery. Feature tours delay value and increase cognitive load —
get to the first win fast; over-automating removes ownership, preserve one meaningful user action.
